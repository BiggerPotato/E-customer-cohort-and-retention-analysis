# Retention Studio Dashboard

This project combines the original Python retention analysis with a static HTML/CSS/JavaScript dashboard and a small local Python server. It reads `monthly_summary.csv` and `cohort_retention.csv`, and uses the project's `Online Retail.csv` for customer/order-level metrics. The analysis creates a separate `days_between_orders.png` so the order-gap panel does not reuse the combined revenue/order-gap report image.

## Start the dashboard

```powershell
python dashboard_server.py
```

Open <http://127.0.0.1:8000>. Keep the terminal open while presenting. The page includes controls for the existing Python tests and the Playwright browser suite. Its Testing & Quality section links to the assessment artifacts.
