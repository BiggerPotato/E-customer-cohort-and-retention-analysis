About the data

This dashboard reads monthly_summary.csv and cohort_retention.csv from the project folder. Metrics are calculated from the available summary data; detailed customer and order measures need source order records.

◎

Limitations

This analysis describes observed behavior. It does not prove why customers return or establish cause and effect. Blank cohort periods mean there is no later-period data for that cohort.
