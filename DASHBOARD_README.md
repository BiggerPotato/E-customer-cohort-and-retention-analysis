# Dashboard entry point

The active local dashboard is the HTML/CSS/JavaScript app served by `dashboard_server.py`. Follow `README_DASHBOARD.md` for launch instructions and `RUNBOOK_DEMO.md` for the assessment demonstration sequence.

`app.py` and `requirements-dashboard.txt` are the earlier Streamlit prototype and are not used by the current dashboard or its tests. Use `python dashboard_server.py` to start the assessment app.
